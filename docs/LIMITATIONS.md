# Implemented scope and limitations

This is a functional development cut toward 0.1, not a claim that every item in the supplied order is complete.

Implemented: project create/open/close with automatic atomic metadata save; CSV/TSV/Parquet import and preview; manual delimiter, decimal, date format, header and all-text options; UTF-8/BOM handling; 100-row pages (API maximum 500), search and database sorting; complete numeric/categorical profiles; missing, nonfinite, duplicate-key, range and IQR candidate rules with up to 100 evidence rows; immutable filter/select/rename/TRY_CAST/arithmetic/sort/group versions; CSV/Parquet and provenance PDF/Markdown/CSV export, globally or per result; descriptive, one-sample t, paired t, Pearson, Spearman, Welch, one-way ANOVA, Mann–Whitney, chi-square and scalar OLS; eight chart forms with editable styling and saved per-version configuration; an editable, executable native node canvas with version selection, typed connections, selective execution and undo; versioned cell/row/column editing; missing-value impact previews and mean/median/mode/constant/drop operations; native settings, keyboard commands, light/dark and external ES/EN string catalogs.

Explicit limits:
- At most 256 columns. In-memory numeric analyses refuse more than 200,000 source rows; they do not silently sample. Profiles/aggregated charts use the full data.
- Scatter/line/area show the first 2,000 complete finite pairs, not a representative random sample. Frequency bars show the top 30 categories. Histogram has 5–100 selectable equal-width intervals, omits empty bins, and uses one bin for a constant variable. Boxplot uses type-7 quartiles and observed 1.5-IQR whiskers; outlier points are counted but not drawn.
- Cancellation waits for the current synchronous DuckDB query to finish; successful query work is discarded before commit when cancelled. Progress reports phases, not a fictitious percentage.
- Import always materializes into the project database. Keeping an external reference or optional raw copy is deferred. Large imports/versions can require substantial free disk; no size estimator or compaction UI yet.
- No arbitrary SQL/expression language, joins, Excel, AI, multiple regression, arbitrary executable workflow nodes or plugin execution. PDF report nodes include statistical results, quality findings, provenance and embedded chart PNGs; text is vector, plots are raster. No post-hoc/multiple-comparison correction, exact Mann–Whitney p-values, Welch ANOVA or Fisher exact test.
- Derived columns support arithmetic with one finite scalar. TRY_CAST may create NULLs; a warning asks the user to review the profile. A dedicated cast-loss count is deferred.
- Scale defaults to unknown and metadata editing is deferred. Type inconsistency is exposed through strict import failures or explicit TRY_CAST/profile comparisons, not a separate per-cell type rule.
- Pearson/Spearman report coefficients and valid n without p-values. Regression reports coefficients, R², residual sum/scale and slope SE; full residual export/diagnostic plots and coefficient confidence intervals are deferred. For constant X or Y, paired analyses explain why the requested coefficient/R² is undefined.
- Existing export destinations are always protected; choose a new name even if the native panel offers replacement. No source can be overwritten through app exports.
- Projects are single-writer. Crash recovery may leave an unreferenced table; manifests refer only to committed tables. Closing before moving/copying a package is required.
- Main navigation/controls have ES/EN catalogs. Some technical procedure text, system dialogs, dynamic copy and engine errors remain English/Spanish; full localization QA is pending.
- Minimum deployment target is macOS 14. Actual host coverage and distribution-signing limitations are in VALIDATION.md; untested OS versions are not presented as validated.
- Paths containing glob metacharacters (`*?[]{}`) are rejected so DuckDB cannot expand one explicitly selected path into additional files; rename the file/folder before importing.
- In-memory paired statistics use IEEE 754 Double. Very large integers/decimals may lose numerical resolution; raw data and profile distinct/min/max remain in their physical database type. Rescale for numerically sensitive analyses.

- ANOVA requires at least two groups and two finite observations per group, assumes independent errors and equal variances, and rejects zero within-group variance. It does not identify which groups differ. Grouped numeric materialization permits at most 100 groups.
- Mann–Whitney uses an asymptotic bilateral normal approximation with tie and continuity corrections. Small groups receive a warning; identical tied values with zero rank variance fail explicitly. A location interpretation additionally requires comparable distribution shapes.
- Chi-square uses counts of complete categorical pairs, at most 50 levels per variable / 2,500 cells, and no Yates correction. Expected-cell diagnostics are explicit. Sparse tables receive warnings; no exact substitute is claimed.
- A saved workflow supports up to 500 boxes. It executes built-in typed operations; no third-party executable nodes. Removing a branch only removes its boxes; datasets and saved results remain in project history. Completed upstream steps survive a downstream failure/cancellation. Undo restores graph structure/configuration; it does not erase physical versions or result history.
- Missing means NULL, plus optional blank/whitespace text and nonfinite numeric values. Media/median require numeric columns and promote filled columns to DOUBLE; very large integer precision may change. An all-missing column cannot acquire a fabricated mean/median/mode. Mode ties choose the smallest observed value deterministically. Imputation warnings accompany subsequent inference; uncertainty is not adjusted statistically.
- Cell edits and row removal use the immutable table’s physical row identity, including after search/sort. A real column named `rowid` must first be renamed because it shadows DuckDB’s identity. Remove at most 10,000 explicitly identified rows per operation; the native page contains at most 100. Editing is a new version, never an in-place update of the source.
- Report nodes accept up to 32 charts per export. Markdown PNG sidecars must travel with the document. Chart caches are regenerated by executing their box after reopening; layout and parameters persist.
- Chart style must be saved explicitly. Histogram interval changes require data refresh. Color is optional presentation, not a change in results.

- Backward loading is supported for schema-1 projects without workflow fields. Older VAPULA binaries cannot read the new missing/manual transformation cases; reopen those projects with this updated app.
