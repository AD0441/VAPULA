# Capturas de la aplicación

Capturas directas de la ventana nativa de VAPULA en el Mac de validación, tomadas durante la preparación de la publicación. No contienen datos personales: el proyecto usa el CSV sintético de 31 filas de las pruebas.

- `flujo.png`: vista general con nueve cajas y ramas de datos/resultados.
- `ausentes.png`: selección de columnas, política y reemplazo por media.
- `estadistica.png`: resultado descriptivo de la versión corregida.
- `graficos.png`: histograma real y controles de diseño.

No se han retocado las capturas ni sus resultados. Las imágenes de `docs/assets/promo` sí son composiciones promocionales generadas a partir de una captura real.
