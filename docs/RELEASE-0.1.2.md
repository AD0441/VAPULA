# VAPULA 0.1.2 — versión preliminar

El escritorio de cajas incorpora una lista de pasos navegable, atajos para cambiar de paso y mostrar paneles, entradas compatibles desde el inspector y nombres que distinguen cada forma de gráfico. Mejora la presentación en oscuro y la adaptación de la vista inferior.

- Catálogo ES/EN y cambio en vivo de controles y mensajes conocidos; se conservan nombres y títulos del usuario.
- HEX inválido con diagnóstico y aplicación desactivada; aviso de contraste para colores personalizados.
- PDF con título, procedencia, leyenda y figura juntos.
- Selector de proyectos con tipo de paquete explícito y enlaces de apoyo coherentes.

**Verificación:** 76 funciones Swift Testing en 16 suites release, regresión PDF reproducida/corregida, recorrido sintético real con las ocho formas, exportaciones PDF/MD y reapertura. [Detalle y límites](USABILITY-STAGE.md).

**Descarga:** `VAPULA-0.1.2-macos-arm64.zip` y `SHA256SUMS.txt`. Apple Silicon; macOS 14 como mínimo de compilación. Host probado: M1/8 GB/macOS 27.2. Firma ad hoc, sin Developer ID ni notarización. Otro Mac y el sistema mínimo continúan pendientes.

La auditoría completa de VoiceOver, la matriz visual, la traducción integral de informes y la prueba de todo el Mac desconectado conservan estado parcial. Esta entrega no añade XLSX, joins ni métodos propuestos. [Estado de requisitos](STATUS.md) · [Límites](LIMITATIONS.md).
