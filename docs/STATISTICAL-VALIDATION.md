# Statistical methods and independent references

Reference generation: `script/generate_references.py`, development-only SciPy 1.18.1 / NumPy 2.5.4, RNG seed 20261029. Committed input/output JSON: `Tests/VapulaTests/Fixtures/statistical-reference.json`. No Python/R executable, package or interpreter is in VAPULA.app.

The reference matrix includes 18 paired datasets (n=3–100, differing ranges, average-rank ties), nine unequal-variance Welch comparisons (group n=2–100; alpha .01/.05/.10), 48 two-sided Student t probabilities (df 1–1000, |t| 0–100), and 18 upper-tail quantiles (p .95/.975/.995, df 1–1000). Values are generated by scipy.stats, not by the Swift implementation.

- Descriptives: finite observations; missing/NaN/±Inf count as exclusions. Welford sample moments, n−1; n=1 returns no sample variance. Type-7 linear quantiles match NumPy default/R default. DuckDB profiles use sample SD and quantile_cont over finite values.
- Pearson: centered covariance normalized by centered sums of squares, bounded to [−1,1] for floating-point rounding; pairwise finite complete cases.
- Spearman: Pearson over average ranks, including ties. No p-value is exposed for either correlation; a distribution-free exact p-value is not claimed.
- Welch: independent finite groups, t=(meanA−meanB)/sqrt(sA²/nA+sB²/nB), Welch–Satterthwaite df. Two-sided p via regularized incomplete beta, modified Lentz continued fraction with 2e−14 convergence threshold / 10,000 iteration ceiling; nonconvergence throws. Critical t via bounded bisection. CI=(difference ± t*SE). Effect: Cohen d_av uses sqrt((sA²+sB²)/2), not a pooled-SD Hedges g.
- OLS: one predictor, centered sums/covariance; no inverse of X'X. Coefficients, R², residual sum of squares, sample residual scale (n−2), slope SE. Constant X/Y or n<3 produce an explanatory failure; overflow is rejected. Full residual diagnostics are pending.
- Boxplot: type-7 Q1/median/Q3 and observed extreme values inside [Q1−1.5 IQR,Q3+1.5 IQR]. Candidate outliers are not confirmed errors.

Tolerances: |actual−reference| ≤ 1e−9 + 1e−8|reference| for summaries, coefficients, Welch and quantiles. Student probability checks use 1e−14 + 1e−9|reference| to keep tail errors visible. Tolerances allow ordering/rounding of independent algorithms; they are not guarantees for every dataset. Near-singular/huge-offset or adversarial magnitudes require further validation. Overflow returns an error rather than a valid NaN/Inf.

Runtime evidence and actual test outcomes are recorded in VALIDATION.md. Passing only edge/no-crash checks would not qualify numerical methods as validated. Numerical reference tests must pass before Welch is distributed.

Primary method references: [SciPy ttest_ind](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html), [SciPy linregress](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.linregress.html), [official DuckDB Swift source](https://github.com/duckdb/duckdb-swift/tree/v1.1.3).

## Expanded general tests

`script/generate_expanded_references.py` generates `expanded-statistical-reference.json` independently using SciPy 1.18.1 / NumPy 2.5.4, seed 20261030: 18 one-sample t cases, 15 paired t, 16 one-way ANOVA, 18 Mann–Whitney and 12 chi-square cases. Their 1,011 scalar expectations supplement the initial 345 comparisons. The optimized suite verifies every expected scalar with absolute 1e−9 + relative 1e−8 tolerance. Passing this finite reference matrix does not establish universal accuracy.

- One-sample t: reference μ₀, n−1 degrees of freedom, bilateral p, confidence intervals and Cohen d. At least two finite values and positive sample variance are required.
- Paired t: complete finite row pairs; the one-sample t calculation is applied to row-wise differences. Exclusions count incomplete source rows, and zero difference variance fails. Cohen d_z uses difference SD.
- Classical one-way ANOVA: centered between/within sums of squares, F probability from regularized beta, eta squared. Each group needs n≥2; zero within variation fails. No post-hoc procedure or unequal-variance ANOVA is implied.
- Mann–Whitney: average ranks for ties; bilateral asymptotic p with tie-adjusted variance and 0.5 continuity correction. Rank-biserial direction refers explicitly to A−B. No exact p-value.
- Pearson chi-square: expected values from row/column margins, chi-square probability from regularized gamma, degrees of freedom and Cramér V. No Yates correction. Reports expected counts below 1/5 and warns about sparse tables. Empty margins, negative counts and totals above Double's exact integer range fail.

Additional integration tests execute these methods on a selected DuckDB version, verify exclusions, persisted results, categorical levels, histogram bin counts, style persistence and schema-1 backward decoding. PDF tests verify readable text, single-result selection, long pagination and footers. Actual outcomes: [VALIDATION.md](VALIDATION.md).
